Thank you for considering contributing to Himalayan Trail Co.

How to contribute

1. Fork the repository and create a branch for your change:

```bash
git checkout -b feat/my-change
```

2. Make small, focused changes and include tests or screenshots when relevant.

3. Commit with clear messages and open a pull request describing the change.

Development workflow

- Run the dev server: `npm install && npm run dev`
- Keep changes focused and open PRs against `main`.
- Rebase or merge main before requesting a review.

Coding style

- The project uses TypeScript and Tailwind CSS. Follow existing patterns for components and utility classes.
- Run `npm run lint` (TypeScript check) before opening a PR.

Reporting issues

- Open an issue with steps to reproduce, expected vs actual behavior, and any relevant logs or screenshots.

Thank you — maintainers will review PRs as soon as possible.
